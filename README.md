# Nomad ChargeKey 240W cap

Double cap for the two USB-C plugs of the [Nomad ChargeKey 240W](https://nomadgoods.com/products/chargekey-v2) keychain cable, for FDM printing. Two hidden spring leaves press on the metal plug shells.

- **Print:** `Nomad_ChargeKey_cap_black_v6.stl`. Backup: `Nomad_ChargeKey_cap_black_v5_1.stl`.
  - Settings: 100 % scale, PLA, floor on the bed, openings up, no supports, 0.12–0.16 mm layers, 3 walls, 100 % infill.
  - Fit it on the cable with the magnetic tips joined.
- **Sources:** `build_cap.py` (CadQuery) and `Nomad_ChargeKey_cap.scad` (OpenSCAD), the same parametric model. `.step` files for CAD.
- **Everything else** (cable measurements, design, formulas, version history, conclusions, rebuild): [KNOWLEDGE_BASE.md](KNOWLEDGE_BASE.md).

Status: v6 checked in CAD, not yet fitted.
